## ✨ Funcionalidades Principais

- 🔄 **Conversão Bidirecional Instantânea:**
  - Digite em Dólar (USD) para calcular o valor correspondente em Real (BRL).
  - Digite em Real (BRL) para calcular o equivalente em Dólar (USD).
  - Cálculo executado dinamicamente no evento `keyup` (ao digitar).
- 💲 **Formatação Monetária Automática:**
  - Ajuste de decimais e pontuações usando a API nativa `Intl.NumberFormat` para a moeda brasileira.
  - Correção de vírgulas e pontos no tratamento dos valores.
- ⚡ **Leve e Sem Dependências:**
  - Construído exclusivamente com tecnologias web nativas (Vanilla HTML, CSS e JavaScript), sem necessidade de instalação de pacotes ou frameworks complexos.

## 🚀 Como Executar o Projeto

Como este projeto utiliza tecnologias web nativas, **não é necessário instalar nenhuma dependência ou gerenciador de pacotes**.

### Opção 1: Abrir diretamente no navegador

1. Baixe ou clone este repositório:
   ```bash
   git clone https://github.com/Matheusg0ulart/converso-dolar-para-real.git
   ```
2. Navegue até a pasta do projeto e dê um duplo clique no arquivo `index.html` (ou abra-o com o navegador de sua preferência).

### Opção 2: Com a extensão Live Server (VS Code)

1. Abra a pasta do projeto no **VS Code**.
2. Caso tenha a extensão **Live Server** instalada, clique com o botão direito no arquivo `index.html` e selecione **Open with Live Server**.
